# Spatial Analytics Test Drive

This project provides hands-on examples and tutorials to help you get started with spatial data analysis and visualisation on Databricks, with a special focus on Australian-based datasets.

## 🗺️ Overview

This repository serves as a practical introduction to spatial analysis, covering fundamental concepts, tools, and real-world applications that help uncover geographical patterns and relationships within datasets.

## 🇦🇺 Australian Data Focus

The examples in this repository use Australian spatial data sources, including:
- **Vector data** (e.g., shapefiles, GeoJSON)
- **Raster data** (e.g., satellite imagery)
- **Lidar data** (e.g., point clouds for terrain and vegetation analysis)

## 🔗 Integration & Apps

You will find Databricks notebook examples and app integrations, such as:
- **Databricks spatial visualisation apps, data serving (fastapi) app**
- **ArcGIS Python API integration** for reading feature service layer

---

Feel free to explore, adapt, and extend these examples for your own Australian spatial analytics projects!
